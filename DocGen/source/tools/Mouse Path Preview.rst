##################
Mouse Path Preview
##################

This interactive preview plays sample mouse paths (using the same WindMouse based algorithm as :code:`TTarget.MouseMove`) between a start and stop point.

- Drag the **Speed**, **Wind** and **Gravity** sliders to see how each shapes the path.
- Adjust **Paths** to play more or fewer samples at once.
- **Click** anywhere to set a new destination (the previous destination becomes the new start).
- Press **Space** (or **New route**) for a fresh random route.
- Hover a legend entry to highlight that path.
